# Деньги — учёт доходов и расходов (PWA для iPhone)

Работает без App Store, без Mac и без платного аккаунта разработчика.
Данные хранятся только на телефоне (localStorage).

## Установка на iPhone
1. Выложите папку на любой HTTPS-хостинг. Проще всего GitHub Pages:
   `Settings → Pages → Branch: claude/income-expense-app-3efir4 (или main) / root → Save`.
2. Откройте полученную ссылку в **Safari**.
3. «Поделиться» → **«На экран Домой»**. Приложение запустится как обычное, в полный экран, и работает офлайн.

## Быстрая запись (Siri / «Команды»)
Приложение принимает запись из ссылки:

- `?q=кофе 300` — расход 300, категория «Еда» определится по слову
- `?q=+50000 зарплата` — доход
- `?q=такси 1,5к` — «к» = тысяча
- `?type=expense&amount=300&cat=Еда&note=кофе` — полная форма

Команда: «Запросить ввод» → «Закодировать URL» → «Текст» (`https://…/?q=` + закодированный ввод) → «Открыть URL».
Подробности — кнопка «Быстрая команда» в приложении.

## Резервная копия
Кнопка «Резервная копия» сохраняет JSON, «Восстановить» загружает его обратно, «Экспорт CSV» — для Excel.
Делайте копию изредка: если удалить иконку с экрана, данные пропадут.
